# VHS Camera

Android-приложение, которое снимает видео так, будто оно записано на VHS-видеокамеру:
мягкая «ленточная» картинка с ореолами резкости, цветные каёмки, полоса переключения
головок внизу кадра, выпадения ленты, штамп даты и времени, моторный зум и звук с
шипением плёнки. Вид, звук и зум подогнаны под три эталонных ролика (замеры — ниже).

## Установка

Готовый файл: [`apk/VHS-Camera.apk`](apk/VHS-Camera.apk) — его пересобирает GitHub Actions
при каждом изменении кода.

1. Скачайте `VHS-Camera.apk` на телефон (в GitHub: открыть файл → **Download raw file**).
2. Откройте его и разрешите установку из этого источника.
3. При первом запуске разрешите доступ к камере и микрофону.

Нужен Android 8.0 или новее.

## Управление

Экран сделан как корпус видеокамеры: видоискатель 4:3 в центре, кнопки по бокам.

| Элемент | Что делает |
|---|---|
| Красная **REC** (или кнопки громкости) | начать / остановить запись; рядом мигает лампочка записи |
| Качелька **T** / **W** (удерживать) | моторный зум: приближение / отдаление, до 6× |
| **MENU** | синее экранное меню: дата, свет, камера |
| **DATE** | включить / выключить штамп даты и времени |
| **LIGHT** | фонарик |
| **CAMERA** | основная / фронтальная камера |
| **PLAY▶** | открыть последний снятый ролик |

В видоискателе поверх картинки показываются `STBY` / `REC` с мигающей точкой, счётчик
ленты и шкала зума — на запись они не попадают.

Ролики сохраняются в галерею, в альбом **DCIM/VHS Camera**: MP4, 960×720 (4:3), H.264
8 Мбит/с, 30 кадров/с, звук AAC моно 48 кГц.

## Что именно воспроизведено

Картинка:

- кадр телефона сначала сводится к 960×720 — средней части 720p-кадра, как на
  эталонных роликах (по вертикали у них полные 720 строк); цифровой зум берётся из
  этого кадра, поэтому при приближении картинка мылится так же;
- строчный фильтр ленты подобран по реальным сюжетам эталона: детали размером
  10–50 пикселей подчёркнуты до +6 дБ, мелочь плавно гаснет, ореол сильнее справа
  от контура; цвет фильтруется так же, как яркость;
- штамп даты и чёрные поля по бокам накладываются после этого фильтра, со своим,
  тоже измеренным, профилем края;
- расхождение каналов: красный на ~1,5 пикселя левее, синий на ~1,9 пикселя правее;
- слабый повтор изображения справа, лёгкое дрожание строк, мягкий шум ленты;
- полоса переключения головок в нижних ~14 строках, редкие выпадения-чёрточки над ней;
- помехи старта ленты в первые кадры клипа (снег, волна, бегущая полоса) и сбой в
  последних кадрах при остановке;
- надпись `PLAY▶` первые 3 секунды записи и штамп вида `PM  3:02` / `MAR.09 2025`
  точечным шрифтом с перечёркнутым нулём.

Зум: линейный по кратности, 0,78× в секунду, старт и стоп мгновенные.

Звук: микрофон ограничен по частоте, выравнивается мягким компрессором, как в
видеокамерах, лёгкая детонация; поверх — шумовая подложка ленты, синтезированная по
замерам: шипение с измеренным спектром и «жужжание» — гребёнка из 28 тонов от 30 Гц
до 1,6 кГц.

## Сборка

Проект собирается обычным Gradle (`./gradlew assembleRelease`, нужны JDK 17 и Android SDK).
В репозитории это делает workflow [`.github/workflows/build.yml`](.github/workflows/build.yml):
собирает APK, кладёт его в `apk/` и прогоняет приложение на эмуляторе Android —
приложение само записывает тестовый ролик, а скрипт проверяет, что файл появился в галерее.

APK подписан ключом `app/vhscam.jks`, который лежит в репозитории специально: так у всех
сборок одна подпись и новая версия ставится поверх старой.

## Устройство кода

| Файл | Назначение |
|---|---|
| `VhsRenderer.kt` | поток OpenGL: кадры камеры → три шейдерных прохода → видоискатель и кодер |
| `assets/shaders/pass_cam.frag` | кадр телефона → кадр камеры 960×720 |
| `assets/shaders/pass_a.frag` | → «кадр ленты» 480×720: цифровой зум, цвет, шум |
| `assets/shaders/pass_b.frag` | строчный фильтр ленты; штамп даты и чёрные поля |
| `assets/shaders/pass_c.frag` | дефекты воспроизведения: каёмки, дрожание строк, выпадения, полоса головок, сбои |
| `TapeRecorder.kt` | кодирование H.264 + AAC, MP4, запись прямо в галерею |
| `VhsAudio.kt` | звук ленты: фильтры, детонация, шипение, фон |
| `CameraController.kt` | Camera2 |
| `PixelFont.kt`, `Osd.kt` | точечный шрифт и штамп даты |
| `CamcorderViews.kt` | кнопки корпуса, индикаторы видоискателя, экранное меню |
| `MainActivity.kt` | экран камеры |
